## Recopilación del estudio

El autor creó el formato de seis tablas y lo rellenó reuniendo información de fuentes de terceros.
La captura real de cuatro temporadas, hasta J9 de 2026/27, se conserva en su copia privada.
No se ha acreditado una autorización para redistribuir públicamente esa recopilación combinada;
por ello no se incluyen sus CSV, matrices, predicciones por partido ni casos individuales.

|---|---|---|
| LaLiga / Opta | Fuente principal declarada de 1.228 resultados | [Condiciones de LaLiga](https://www.laliga.com/informacion-legal/legal-web): no se ha acreditado una licencia abierta para publicar la recopilación. |

La procedencia es la declarada por la recopilación; no demuestra verificación exhaustiva de cada campo.
No se afirma que LaLiga sea titular de todas las cifras deportivas aisladas. La estructura propia,
los posibles derechos sobre bases de datos y las condiciones de obtención son cuestiones distintas.
Citar una fuente no sustituye por sí solo el permiso que pudiera resultar necesario.

## Qué se publica

Código y configuraciones, explicaciones del estudio, resultados estadísticos agregados y plantillas
sin registros. La distribución no concede derechos sobre la base subyacente. Los informes y salidas
de grupos se mantienen como resultados del análisis; no se ofrece una base oficial reutilizable.

El usuario debe obtener datos reales con condiciones adecuadas para su uso previsto y documentar
sus fuentes. El prompt de recopilación no evita restricciones, no garantiza acceso gratuito a todo
el historial y no acredita permiso para publicar después los archivos que se completen.

## Reproducción

El código es inspeccionable y puede ejecutarse aportando datos compatibles. **La descarga por sí
sola no permite reproducir exactamente las métricas publicadas**: haría falta la misma captura.
Una fuente diferente, una corrección o una cobertura parcial pueden cambiar las cifras.
La documentación no promete acceso a la captura privada ni una cesión individual de esa base.
