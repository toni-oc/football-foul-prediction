# Datos locales del usuario

Crea aquí la carpeta `actualizados`, copia los siete archivos de `data/plantillas` y completa
los CSV con datos reales. Sigue [docs/guia_de_uso.md](../../docs/guia_de_uso.md).
No se distribuye una carpeta `estudio_v1` ni ningún CSV real.
El contenido de `actualizados` está excluido de Git.
